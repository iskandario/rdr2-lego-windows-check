# Assassin Traversal — RDR2, Windows x64

**0.1.0 EXPERIMENTAL. Собранный игровой ASI-прототип, НЕ проверенный в самой игре.**
Это первая механика зацепа за уступ, виса и подъёма внутри настоящей RDR2.
Не отдельная игра, не диагностическая программа, не полный перенос паркура Unity.
Анимация пока заменена позой из штатного RDR2 vault-клипа: руки могут не совпасть
с краем, движения могут выглядеть неестественно. Зацеп в прыжке, перемещение вдоль
карниза, отскоки от стен и анимации Assassin's Creed **не реализованы**.

## Скачать и установить

Скачай **AssassinTraversal-Windows-x64-experimental.zip** из
[экспериментального релиза](https://github.com/iskandario/rdr2-lego-windows-check/releases/tag/traversal-v0.1.0).
Не `Source code.zip` и не старый `CHECK-WINDOWS.cmd`.

1. Полностью закрой RDR2. Распакуй **весь ZIP** в обычную папку — не запускай из WinRAR.
2. Нужны **ScriptHookRDR2 и ASI loader**. Скачиваются отдельно у
   [Alexander Blade](https://www.dev-c.com/rdr2/scripthookrdr2/).
   Следуй его инструкции: runtime `ScriptHookRDR2.dll` и loader `dinput8.dll`
   кладутся рядом с `RDR2.exe`. Не копируй SDK или чужие DLL со случайных сайтов.
   Если уже установлен другой загрузчик, не заменяй его вслепую.
   LML, Rampage и Assassin's Creed Unity для ЭТОГО прототипа не требуются.
3. Запусти `INSTALL.cmd`, выбери `RDR2.exe`.
   Папку игры можно открыть в Steam → RDR2 → Управление → Просмотреть локальные файлы.
4. Прочти предупреждение и введи `INSTALL`. Установщик сначала копирует и проверяет
   сохранения из Documents в `Documents\RDR2-Traversal-Backups\<дата>\Profiles`.
   Затем добавляет только `AssassinTraversal.asi` и `AssassinTraversal.ini`.
   Существующие файлы не перезаписывает. В сеть ничего не отправляет.
5. Запусти обычную RDR2 через Steam и выбери **сюжетный режим**.

Твой отчёт показывает RDR2 **1.0.1491.50** — это целевая версия, но совместимость
ещё не подтверждена запуском. Нужен ScriptHook, поддерживающий именно твою версию.
Файлы сборки не подписаны сертификатом. Не отключай антивирус; при предупреждении
проверь исходники/контрольные суммы, не обходи защиту вслепую.

## Как проверить

Сделай отдельное ручное сохранение и выключи автосохранение. Первый тест —
невысокая сплошная стена/платформа **1.3–2.6 м**, широкая плоская площадка сверху,
свободное место над головой. Не крыша высотного здания и не тонкий забор.

| Клавиша | Действие |
|---|---|
| **F8** | Включить/выключить прототип (изначально выключен) |
| **G** | Стоя неподвижно лицом к стене, попытаться зацепиться |
| **E** | Из виса подтянуться на площадку |
| **Q** | Отпустить край |
| **F9** | Аварийно отпустить край и отключить мод |

Нужно подходить близко (лучше около 0.5–0.9 м до стены), стоять пешком без боя.
Поддерживаются Артур/Джон; не лошадь, транспорт или персонаж, заменённый трейнером.
Надпись слева сверху показывает состояние/причину отказа. Вис ограничен 15 секундами.
Alt-Tab, пауза, смерть или потеря управления отменяют действие, когда скрипт снова
получает выполнение. F8 включает его заново. Падение наносит обычный урон.
Не сохраняй игру во время виса. Только клавиатура в этой версии.

## Ограничения и восстановление

- **Не запускай Red Dead Online с установленными модами.** Проверка сетевой сессии
  в коде — дополнительная страховка, не разрешение использовать мод онлайн.
- Нельзя использовать developer hot-reload (`ScriptHookRDR2.dev`, Ctrl+R) во время
  работы мода. Сначала F9, затем полностью выйти из игры. Из `DllMain` нельзя
  безопасно восстанавливать персонажа вызовами игровых функций.
- Не сочетай с другими модами телепортации/анимаций/движения при первом тесте.
- Нет noclip, бессмертия, переписывания RPF или доступа к учётным данным.
- Если зацеп не сработал, попробуй широкую площадку: неподходящие поверхности,
  задержки raycast и препятствия отклоняются, а не игнорируются.
- Если поза сломана, выйди из игры и поставь `Animate=0` в `AssassinTraversal.ini`.
  Это оставляет только тест движения без позы — не исправляет саму анимацию.
- Для удаления закрой игру и убери **только** `AssassinTraversal.asi` и
  `AssassinTraversal.ini`. Лог `AssassinTraversal.log` можно сохранить для разбора.
  Установленные отдельно загрузчики удаляй по их инструкции, учитывая другие моды.
- Если понадобится вернуть сохранения: закрой игру и лаунчер, сохрани текущую
  `Profiles` отдельно, затем верни копию `Profiles` из резервной папки. Учти Steam
  Cloud: не выбирай облачную перезапись вслепую.

При проблеме пришли **AssassinTraversal.log** из папки игры и короткое видео:
F8 → подойти к стене → G → E/Q. Пароли и файлы игр присылать не надо.

## Что проверено и что нет

Автоматическая сборка: [Windows workflow](../../.github/workflows/parkour-windows.yml).
Тесты геометрии и состояний не запускают RDR2: проверяют стены/площадки/препятствия,
невалидные результаты запросов, 30/60/144 FPS, таймаут и отпускание.
Успешная компиляция **не доказывает**, что мод загрузится, правильно найдёт уступ
или красиво проиграет анимацию в твоей игре. Первая сборка предназначена для
согласованного экспериментального теста; работающее видео пока отсутствует.

Сборка из исходников: Windows x64, Visual Studio 2022 C++, CMake 3.21+.
Укажи `-DRDR2_SDK=<путь к SDK>` при CMake-конфигурации.
Workflow закрепляет SDK commit `ef53fc71e0ad95cfa8e72a63f15e1c6aa38091de`.
SDK/загрузчик/игровые ресурсы не входят в релиз.
