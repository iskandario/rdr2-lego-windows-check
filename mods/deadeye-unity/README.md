# Dead Eye-inspired prototype for AC Unity — SOURCE ONLY

Это уже код игровой механики, **не очередной сборщик отчёта**. Но это также **не готовая проверенная DLL и не полный кроссовер**.

Первый этап: замедление времени внутри Unity, удержание F6, запас 6 секунд, восстановление запаса при отпускании, отключение F7, индикатор. Коэффициент 18% выбран для прототипа; это не воспроизведение точных правил RDR2. Артур, прицеливание по меткам и перенос моделей не реализованы.

## На чём основано

Использована процедура [universal-modder](https://github.com/rehan-remade/universal-modder) и разобраны реальные исходники [ACUFixes для Unity 1.5.1](https://github.com/antr1x/ACUFixes). Управление временем уже есть в ACUFixes; наш код использует его, а не выдуманные адреса. Точный commit закреплён в скриптах. Сторонние исходники, игровые ресурсы и загрузчик в этот архив не включены.

## Проверено / не проверено

Пройдены локальные тесты C++-логики. Windows DLL ещё не собрана и не проверена в игре. Фотография отчёта подтверждает наличие двух EXE, но не совместимость загрузчика. Подробности: [MODLOG.md](MODLOG.md).

Загрузчик upstream отключает внутреннюю проверку целостности. Его установку здесь не выполняли; сначала требуется уточнить совместимость и характер этой защиты. Не обходить DRM/античит/проверку владения. Не использовать в кооперативе или Online. Галочка в меню — подтверждение пользователя, **не автоматическое определение офлайн-режима**.

## Сборка разработчиком на Windows

Нужны Git и Visual Studio 2022 C++ Build Tools с Windows SDK. Это подготовка исходников и сборка, не установщик мода:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Windows.ps1
```

Скрипт создаёт новый временный checkout закреплённого upstream, добавляет наши исходники и собирает только gameplay-плагин `ACUFixes.dll`. Не строит загрузчик, не меняет игры/реестр, не копирует DLL в игру. Повторное использование грязного checkout запрещено.

До установки: выяснить совместимость loader/EXE, подтвердить офлайн-режим, сделать резервные копии сохранений и конфигов. Этот мод заменяет gameplay-DLL ACUFixes, а не добавляется рядом вторым экземпляром. Остальные функции upstream сохраняются; настройки и их влияние нужно проверить отдельно. Нельзя выдавать успешную компиляцию за успешный запуск игры.

Код нового эффекта создан с помощью ИИ. За низкоуровневое исследование Unity и существующее управление временем — благодарность NameTaken3125 и antr1x. Новая логика не скопирована из RDR2.
